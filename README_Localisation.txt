ADJUSTMENT FINDER - LOCALISED CONFIGURATION PROTOTYPE v0.6

The original general-school index.html has been extended with a runtime localisation layer.

WHAT CHANGES WITH LOCATION
- Plan/support terminology
- Progress-step/UI labels prepared for localisation
- More detail label
- Documentation destination/card
- Generator field headings
- Copy-to-plan action label
- Framework context and reference names displayed in the header
- HTML language setting

WHAT DOES NOT CHANGE
- Barrier dataset
- Adjustment recommendations
- Trial/review workflow
- More detail popovers
- Saved demonstration records

LOCALES INCLUDED FOR STRUCTURAL TESTING
- General / International
- Australia - Queensland
- Australia - New South Wales
- Australia - Victoria
- United Kingdom - England
- United States

IMPORTANT
Regional wording in this prototype is configuration scaffolding and should be verified against primary jurisdictional sources before being treated as policy guidance. The General / International locale is the default.

The selected locale is stored in browser localStorage and the interface re-renders immediately when changed.
